Политика конфиденциальности Privacy Policy

Общие положения

XCH2VPN — VPN-сервис с дополнительными функциями безопасности для работы с Web3. Мы серьезно относимся к конфиденциальности данных. В этом документе описано, какую информацию мы собираем, как ее используем и каковы ваши права.

General Provisions

XCH2VPN is a VPN service with additional security features for Web3 interactions. We take data privacy seriously. This document describes what information we collect, how we use it, and your rights.

VPN-логи и анонимность

Строгий запрет на логирование. Мы не ведём логи активности пользователей. Это значит, что мы никогда не храним и не видим:

  • IP-адреса пользователей
  • Посещённые сайты (включая dApps)
  • Время и продолжительность сеансов
  • Объём переданного трафика

Единственная техническая информация, необходимая для работы сервиса — это активный статус подписки и технические данные для поддержания соединения. Эти данные автоматически удаляются при завершении сессии.

VPN Logs and Anonymity

Strict no-log policy. We do not log user activity. This means we never store or see:

  • User IP addresses
  • Visited websites (including dApps)
  • Session time and duration
  • Amount of traffic transferred

The only technical information necessary for the service is active subscription status and connection maintenance data. This data is automatically deleted when the session ends.

Информация о подписке

Для работы сервиса мы получаем информацию о статусе вашей подписки через App Store. Это включает:

  • Идентификатор транзакции (transaction ID)
  • Идентификатор продукта (product ID)
  • Дата активации и дата истечения подписки
  • Статус подписки (активна/неактивна)

Эта информация используется исключительно для предоставления доступа к VPN-сервису и не передаётся третьим лицам.

Subscription Information

To provide the service, we receive information about your subscription status through the App Store. This includes:

  • Transaction ID
  • Product ID
  • Activation date and expiration date
  • Subscription status (active/inactive)

This information is used solely to provide access to the VPN service and is not shared with third parties.

Данные VPN-профиля

При активации подписки сервер выдаёт каждому пользователю персональный PSK-ключ и адрес сервера. Эта информация:

  • Генерируется автоматически при активации подписки
  • Не содержит персональных данных
  • Привязана к вашему аккаунту App Store только через transaction ID
  • Используется исключительно для установки защищённого VPN-соединения

Ваш PSK-ключ никогда не передаётся третьим лицам и не сохраняется в открытом виде.

VPN Profile Data

Upon subscription activation, the server issues each user a personal PSK key and server address. This information:

  • Is generated automatically upon subscription activation
  • Contains no personal data
  • Is linked to your App Store account only via transaction ID
  • Is used exclusively to establish a secure VPN connection

Your PSK key is never shared with third parties and is not stored in plain text.

Блокировка рекламы и трекеров (Web3 Firewall)

XCH2VPN использует базу из более чем 26 000 фишинговых и вредоносных доменов для защиты пользователей. Эта база обновляется каждые несколько часов.

  • Мы не передаём информацию о ваших посещениях
  • База доменов обновляется автоматически и не содержит персональных данных
  • Фильтрация происходит локально на устройстве
  • Список заблокированных доменов хранится только на устройстве и не передаётся на сервер

Ad and Tracker Blocking (Web3 Firewall)

XCH2VPN uses a database of over 26,000 phishing and malicious domains to protect users. This database updates every few hours.

  • We do not share information about your visits
  • The domain database updates automatically and contains no personal data
  • Filtering happens locally on the device
  • Blocked domains list is stored only on the device and is not sent to the server

Web3-кошелёк и транзакции

XCH2VPN позволяет подключать Web3-кошелёк (MetaMask и другие) через протокол WalletConnect. При этом:

  • Приложение никогда не запрашивает и не хранит приватные ключи
  • Все подписи происходят в вашем кошельке
  • Анализ транзакций выполняется локально на устройстве
  • Адрес кошелька отображается в интерфейсе и — только когда вы сами используете сканер транзакций или проверку approvals — передаётся поставщикам блокчейн-данных (Alchemy, Etherscan) исключительно для выполнения этой конкретной проверки
  • История транзакций не сохраняется на наших серверах

Мы не отправляем поставщикам блокчейн-данных ничего сверх того, что технически необходимо для запрошенной вами проверки.

Web3 Wallet and Transactions

XCH2VPN allows connecting a Web3 wallet (MetaMask and others) via WalletConnect protocol. At the same time:

  • The app never requests or stores private keys
  • All signatures happen in your wallet
  • Transaction analysis is performed locally on the device
  • The wallet address is shown in the interface and — only when you actively use the transaction scanner or approvals check — is sent to blockchain data providers (Alchemy, Etherscan) solely to perform that specific check
  • Transaction history is not stored on our servers

We do not send blockchain data providers anything beyond what is technically necessary for the check you requested.

Передача данных третьим лицам

Мы не продаём ваши данные. В приложении нет рекламы и нет собственной аналитики или трекинга, отслеживающих вас между сайтами или сессиями.

При этом ряд Web3-функций технически требует обращения к специализированным внешним сервисам — без этого сами функции не могут работать:

  • Alchemy и Etherscan — при сканировании транзакции перед подписью или проверке approvals им передаётся адрес вашего кошелька и данные транзакции, необходимые для этой конкретной проверки
  • WalletConnect (Reown) — инфраструктура подключения кошелька; видит факт и метаданные сессии подключения
  • DuckDuckGo — если вы используете поиск через адресную строку браузера, поисковый запрос уходит к нему напрямую
  • Google DNS и Cloudflare DNS — при включённом VPN ваши DNS-запросы (какие домены вы посещаете) обрабатываются этими DNS-серверами, на которые настроен туннель

Эти сервисы действуют в рамках собственных политик конфиденциальности. Мы передаём им только то, что технически необходимо для запрошенной вами функции, и не используем их для рекламы или отслеживания.

Единственное дополнительное исключение — когда раскрытие требуется по закону, но только в пределах, предусмотренных законодательством, и с соблюдением ваших прав на конфиденциальность.

Third-Party Data Sharing

We do not sell your data. The app contains no advertising and no analytics or tracking of our own that follows you across sites or sessions.

That said, several Web3 features technically require contacting specialized external services — without this, those features could not function:

  • Alchemy and Etherscan — when you scan a transaction before signing or check your approvals, your wallet address and the relevant transaction data are sent to them solely to perform that specific check
  • WalletConnect (Reown) — the wallet-connection infrastructure; it sees the fact and metadata of a connection session
  • DuckDuckGo — if you use the browser's address bar to search, your query goes directly to it
  • Google DNS and Cloudflare DNS — while the VPN is connected, your DNS queries (which domains you visit) are handled by these DNS servers, which the tunnel is configured to use

These services operate under their own privacy policies. We send them only what is technically necessary for the feature you requested, and we do not use them for advertising or tracking.

The only additional exception is disclosure required by law, and only to the extent required by such law, with full respect for your privacy rights.

Хранение данных

Все данные, которые могут быть сохранены:

  • VPN-конфигурация (сервер, порт, PSK) хранится локально на устройстве и в системном профиле VPN
  • Настройки приложения (режим туннеля, kill switch) хранятся локально
  • Статус подписки кэшируется на устройстве для быстрой проверки
  • Никакие данные не хранятся на сервере после завершения сессии

Data Storage

All data that may be stored:

  • VPN configuration (server, port, PSK) is stored locally on the device and in the system VPN profile
  • App settings (tunnel mode, kill switch) are stored locally
  • Subscription status is cached on the device for quick verification
  • No data is stored on the server after the session ends

Безопасность

XCH2VPN использует современные протоколы шифрования для защиты вашего соединения:

  • Шифрование: ChaCha20-Poly1305 с ECDH-рукопожатием
  • Транспорт: WebSocket с TLS 1.2+
  • Аутентификация: Персональный PSK-ключ на каждого пользователя
  • Kill Switch: Блокировка интернета при обрыве VPN

Эти меры обеспечивают полную конфиденциальность ваших данных при передаче.

Security

XCH2VPN uses modern encryption protocols to protect your connection:

  • Encryption: ChaCha20-Poly1305 with ECDH handshake
  • Transport: WebSocket with TLS 1.2+
  • Authentication: Personal PSK key per user
  • Kill Switch: Internet blocking on VPN disconnection

These measures ensure complete confidentiality of your data during transmission.

Удаление данных

Вы можете удалить весь VPN-профиль через настройки приложения (кнопка «Удалить VPN-профиль»). При удалении приложения:

  • Локальные данные удаляются с устройства
  • VPN-профиль удаляется из системных настроек iOS
  • Данные на сервере не хранятся, поэтому удалять их не требуется

Ваш PSK-ключ перестаёт быть активным при отмене подписки или её истечении.

Data Deletion

You can delete the entire VPN profile through the app settings (the "Remove VPN Profile" button). When you delete the app:

  • Local data is deleted from the device
  • The VPN profile is deleted from iOS system settings
  • No data is stored on the server, so there is nothing to delete

Your PSK key becomes inactive when the subscription is cancelled or expires.
